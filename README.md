- `.nojekyll` — tells GitHub Pages to serve files as-is

## Publish on GitHub Pages

1. Create a public repository on GitHub (for example `muhammadfarhaiqbal`)
   — or use an existing repo.
2. Upload all files in this folder to the repository root
   (`index.html`, `style.css`, `app.js`, `README.md`, `.nojekyll`,
   and the `assets/` folder).
3. In the repository: **Settings → Pages → Deploy from a branch**,
   choose the `main` branch and the `/ (root)` folder, then Save.
4. The site will be live at
   `https://muhammadfarhaiqbal.github.io/` (or
   `https://muhammadfarhaiqbal.github.io/<repo-name>/` if the repo
   has a different name).
